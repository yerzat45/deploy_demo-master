# 11_ws — таймеры с WebSocket

Браузерный клиент, PostgreSQL, Express, Knex и WebSocket.

## Запуск

1. Создайте PostgreSQL-базу `07_timers_pg`.
2. Скопируйте `.env-sample` в `.env` и укажите параметры своей базы. Никогда не
   добавляйте настоящий `.env` в Git.
3. Установите зависимости: `npm install`.
4. Запустите проект: `npm run dev`.
5. Откройте `http://localhost:3000`.

Миграции выполняются автоматически перед запуском.

## Продакшен

Проект рассчитан на запуск одним процессом PM2 за Nginx. Nginx должен
проксировать HTTP и WebSocket на `http://127.0.0.1:3000`. При открытии сайта по
HTTPS браузер автоматически подключается по `wss://` к тому же домену.

Не запускайте несколько экземпляров (`pm2 -i 4`): список WebSocket-клиентов
хранится в памяти одного процесса.

## WebSocket-сообщения

Сразу после открытия соединения клиент отправляет:

```json
{ "type": "auth", "token": "SESSION_TOKEN" }
```

После успешной аутентификации сервер отправляет `all_timers`. После создания
или остановки таймера он повторно отправляет актуальный `all_timers`. Каждую
секунду сервер отправляет `active_timers` с пересчитанным полем `progress`.
